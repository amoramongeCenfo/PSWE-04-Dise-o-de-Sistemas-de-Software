# SmartBilling Connect

> Diseño de Software — PSWE-04
> Universidad Cenfotec · Maestría Profesional en Ingeniería del Software

Plataforma de facturación electrónica inteligente para PYMES que venden por redes sociales y canales digitales. Centraliza la gestión de clientes, cotizaciones, facturación electrónica y la automatización de flujos comerciales.
